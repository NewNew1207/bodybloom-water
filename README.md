# Body•Bloom Water

Persoonlijke drinktracker in Body•Bloom stijl (NL / FR).

- Regenboog die vol loopt naarmate je drinkt
- Infrarood trainingsdag en "na je sessie"-moment
- Week- en maandoverzicht, reeks "dagen in bloei"
- Achteraf noteren, eigen fles als snelknop
- Maandrapport als PDF (A4)

Je gegevens blijven op je eigen toestel (in de browser). Er gaat niets naar een server.

Bloom where you are planted.
